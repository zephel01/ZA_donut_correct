# 同梱レシピ一覧

`recipes/` フォルダに同梱されているレシピの一覧です。使うレシピは `config.json` の `recipe` に**ファイル名（拡張子なし）**で指定します。

```json
{ "recipe": "shiny1" }
```

自作レシピの作り方は [USER_RECIPE_GUIDE.md](USER_RECIPE_GUIDE.md) を参照してください。

- **NAME** は「ドーナツの種類 きのみと数」です。NAME では「いじげん」「のみ」を省いています（同梱レシピのきのみはすべていじげんのきのみ）。正式な名前は「きのみと数」の列を見てください。
- **モード**は `TARGETS` で決まります。`'shiny'` を含めば色違いモード、それ以外はどうぐモードです。
- `CATEGORY` は分類用のラベルで、動作には影響しません。
- `TARGETS` が `['general']` のレシピ（sour1・sour2）も、`'shiny'` を含まないのでどうぐモード（どうぐ＋どっさり）で動きます。
- 各レシピの先頭のコメントは [ZAドーナツシミュレーター](https://zadonutsimulator.zephyr.com/) の出力と同じ形式です。1行目がドーナツの種類と付く可能性のあるパワー、2行目が使うきのみと数です。

## 入力操作（STEPS）

各レシピは、食材選択画面でのボタン操作の並びとして定義されています。どのステップも `pressRep`（同じボタンを `repeat` 回押す）で、押下時間は十字キー 0.05 秒・A ボタン 0.1 秒、間隔は 0.1 秒です。

表記: `↑n` = 十字キー上を n 回、`A×n` = A ボタンを n 回

| レシピ名 | 操作の並び | 食材の合計数（A の回数） |
|---|---|---|
| `shiny1` | ↑5 → A×4 → ↑3 → A×4 | 8 |
| `shiny2` | ↑8 → A×8 | 8 |
| `shiny3` | ↑5 → A×6 → ↑3 → A×2 | 8 |
| `shiny4` | ↑5 → A×6 → ↑4 → A×1 → ↑5 → A×1 | 8 |
| `recipe1` | ↑1 → A×4 → ↑5 → A×4 | 8 |
| `recipe2` | ↑6 → A×8 | 8 |
| `recipe3` | ↑1 → A×1 → ↑2 → A×4 → ↑1 → A×3 | 8 |
| `sour1` | ↑1 → A×2 → ↑3 → A×6 | 8 |
| `sour2` | ↑1 → A×2 → ↑2 → A×2 → ↑1 → A×2 → ↑2 → A×2 | 8 |
| `sour3` | ↑3 → A×1 → ↑1 → A×1 → ↑33 → A×6 | 8 |
| `sour4` | ↑3 → A×1 → ↑1 → A×1 → ↑2 → A×1 → ↑31 → A×5 | 8 |
| `rainbow1` | ↑1 → A×2 → ↑3 → A×4 → ↑5 → A×1 → ↑1 → A×1 | 8 |
| `rainbow2` | ↑1 → A×5 → ↑4 → A×1 → ↑2 → A×1 → ↑3 → A×1 | 8 |
| `rainbow3` | ↑1 → A×2 → ↑3 → A×4 → ↑3 → A×1 → ↑2 → A×1 | 8 |
| `rainbow4` | ↑1 → A×6 → ↑1 → A×1 → ↑18 → A×1 | 8 |
| `rainbow5` | ↑1 → A×1 → ↑2 → A×1 → ↑1 → A×5 → ↑10 → A×1 | 8 |
| `rainbow6` | ↑3 → A×1 → ↑1 → A×5 → ↑2 → A×1 → ↑8 → A×1 | 8 |
| `rainbow7` | ↑3 → A×5 → ↑3 → A×2 → ↑1 → A×1 | 8 |
| `rainbow8` | ↑1 → A×1 → ↑2 → A×6 → ↑13 → A×1 | 8 |

> `sour3` は店売りのナモのみを使います（↑33 で店売りナモの位置）。ZAドーナツシミュレーターの計算ではサワー250・ビター145 で、パワーはすべて Lv1 相当です。Lv1 は今の画像では判定できないため、自動厳選では成功判定になりません。
>
> `sour4` は sour3 の店売りナモ1個をいじげんカシブに替えたもので、サワー325 になりサワー系パワーが Lv2 になります。`level_size` と `level_extra` を `2` にして使います。どうぐの種類は抽選なので、`item_class` に一致したものだけが成功になります。

> カーソルの移動量は**食材リストの並び順と所持状況**に依存します。所持していない食材があったり並び順が違ったりすると、別の食材が選ばれます。新しく使うレシピは、最初に `debug_log: true` で1回動かし、実際に選ばれる食材を目で確認してください。

## レシピ別の推奨設定

### 色違い厳選（shiny1〜shiny4）

```json
{
  "recipe": "shiny1",
  "type": "Dragon",
  "size": "oyabun",
  "level_size": 3,
  "level_extra": 3
}
```

ほかくパワーが付くレシピ（shiny1・shiny3・shiny4）では、ほかくパワーも条件にできます。

```json
{
  "recipe": "shiny4",
  "type": "Dragon",
  "size": "oyabun",
  "enable_capture_power": true,
  "level_capture": 2,
  "capture_compromise": true
}
```

### どうぐパワー集め（recipe1〜3, sour1〜4, rainbow1〜8）

```json
{
  "recipe": "recipe1",
  "item_class": "kinomi",
  "level_size": 3,
  "level_extra": 3
}
```

どうぐモードでは、`level_size` が**どっさりパワー**、`level_extra` が**どうぐパワー**のレベルになります。

## レシピの追加・差し替え

- `recipes/` に `.py` ファイルを置くだけで、次回の起動時に自動検出されます（起動ログの `[System] Available recipes:` に表示されます）。
- [ZAドーナツシミュレーター](https://zadonutsimulator.zephyr.com/) で作ったレシピファイルも、そのまま `recipes/` に置いて使えます。
- 必須の変数は `NAME` / `STEPS` / `TARGETS` です。1つでも欠けていると起動時にエラーになります。

詳細は [USER_RECIPE_GUIDE.md](USER_RECIPE_GUIDE.md) を参照してください。
